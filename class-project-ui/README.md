# Briefly Wire — class UI (React)

Vite + React + React Router. Same flows as the archived static HTML in `archive-static-html/`.

## Run locally

```bash
cd class-project-ui
npm install
npm start
```

Open the URL shown in the terminal (default **http://localhost:5173**).

- **Home** — hub
- **Read & summarize** — AI summary (Use Case 1)
- **Notifications** — settings + `localStorage` (Use Case 2)

## Build

```bash
npm run build
npm run preview
```
